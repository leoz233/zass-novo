# ZASS Dental Clinic

Site institucional estático em HTML, CSS e JavaScript puros, preparado para hospedagem na Vercel.

## Prévia local

Abra `index.html` no navegador ou execute `python -m http.server 4173` na raiz do projeto.

O conteúdo público está em `index.html`, `css/`, `js/` e `assets/`. Os dados de contato ficam centralizados no bloco `EMPRESA` de `js/main.js`.
